01 / ABOUT

A real project, not a demo screen.

PROJECT GOAL

Learn software development by building something people can actually use.

Thunder_Community started as an experimental class-community social app and evolved into a multi-part system with a Flutter client, a Node.js backend, WebSocket synchronization, and SQLite persistence.

The project is non-commercial and intended for learning, personal development, and use by trusted classmates and friends.

APPFlutter + Dart

Responsive UI for desktop and mobile.

BACKENDNode.js

HTTP APIs and real-time WebSocket events.

DATASQLite

Accounts, messages, games, notifications, and more.

03 / FEATURES

Built around real interactions.

A1

Real-time chat

Lobby, custom rooms, and private messages with synchronized state.

A2

Media messaging

Images, videos, stickers, emoji, GIFs, and polls through the chat system.

A3

Voice rooms

Each chat context has a corresponding voice room with live participant state.

A4

Multiplayer games

Shared game state, turn flow, votes, roles, bots, and match results.

A5

Accounts & economy

Profiles, avatars, coins, inventory, leaderboards, and game history.

A6

Administration

Server-side permissions, account moderation, announcements, and content controls.
